# Calculadora pequeña
## Enlace a la web: 
https://mariacarrascal540.github.io

## Descripción de las funcionalidades

- Campo de información: debajo de los botones hay un texto que cambia después de cada operación. Dice qué operación se ha hecho, el resultado y si es menor que 100, está entre 100 y 200 o es mayor que 200.
- Operaciones unarias: cuadrado, inverso, valor absoluto, factorial, cubo, raíz cuadrada y potencia.
- Operaciones binarias: suma, multiplicación, resta y división
- Operaciones con CSV: usando listas hace lo siguiente: suma, ordena, invierte, elimina el último, calcula la media y elimina la posición que desees.
- Gestión de errores: la función validate() comprueba lo que escribe el usuario antes de hacer la operación. Si algo está mal, sale un mensaje explicando el error.
- Registro de errores: todos los errores se guardan con la hora. Hay un botón (Ver errores) con el que se pueden ver todos.
- El último botón que pulsas se queda resaltado.
- Teclado: se puede usar sin ratón. Con la tecla Tab se pasa de un botón a otro, y hay atajos: Enter(=),+,-,*,/.
